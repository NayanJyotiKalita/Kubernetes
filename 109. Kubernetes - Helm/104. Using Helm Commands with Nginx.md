# Using Helm Commands with Nginx

## Objective
You are tasked with performing basic **Helm operations** to manage an Nginx deployment using the **Bitnami Helm chart.**

This exercise will help you understand **installing, upgrading, and verifying** Helm releases in a Kubernetes cluster.

## Instructions
Use the Bitnami Nginx Helm chart to perform the tasks below. Make sure to verify your changes using helm and kubectl commands.

### Task 1: Install the Nginx Helm Chart

  1. Add the Bitnami Helm repository (https://charts.bitnami.com/bitnami) and update it. Use the local alias bitnami.

  2. Install the Nginx Helm chart with the following requirements:

      - Release name: my-nginx

      - Service type: ClusterIP

      - Replica count: default (1)

  3. Verify the installation:

      - List Helm releases

      - Check all Kubernetes resources deployed by the release

### Task 2: Upgrade the Nginx Release

  1. Upgrade the my-nginx release with the following changes:

      - Replica count: 2

      - Service type: ClusterIP (retain)

  2. Verify the changes:

      - Ensure 2 pods are running

      - Confirm the service type is still ClusterIP

## Expected Outcome
  1. Helm release my-nginx is installed and upgraded successfully.

  2. Initial deployment has 1 pod, upgraded deployment has 2 pods.

  3. Service type is ClusterIP throughout.
